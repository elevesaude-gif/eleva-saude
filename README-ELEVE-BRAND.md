# eLeve Saúde — assets para o projeto

Coloque a pasta `public/brand` dentro do projeto Next.js:

C:\Projetos\eleva-saude\public\brand

Arquivos principais usados no código:
- eleve-logo-principal.png — usar em header claro
- eleve-logo-alternativo.png — usar quando precisar de layout horizontal com ícone + nome
- eleve-icone.png — usar em favicon, selo, loading ou detalhe pequeno
- eleve-logo-negativo.png — usar em fundo azul petróleo/escuro
